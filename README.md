# Smart Factory IoT Monitoring System

## 📌 Overview
This project was developed during my **IoT Internship at Emertxe Information Technologies**.  
It focuses on monitoring factory parameters using sensors and Arduino, with simulation in PICSim Lab and cloud visualization using ThingsBoard.

## 🛠️ Tech Stack
- **Languages:** C/C++ (Arduino)  
- **Tools & IDEs:** Arduino IDE | VS Code | PICSim Lab  
- **Cloud Platform:** ThingsBoard (IoT Cloud for dashboards)  
- **Other Tools:** Git | GitHub | pgAdmin4  

## 📂 Project Structure
- `/code/node1` → Arduino code for Node 1  
- `/code/node2` → Arduino code for Node 2  
- `/simulation` → PICSim Lab warehouse setup  
- `/presentation` → Internship PPT  
- `/demo` → Screenshots or sample outputs  

## 🎥 Demo Video
Watch my project demo here: [YouTube Link](https://youtu.be/Z6i_kuj3n3s?si=2l2gFVu4tneBVHfp)

## 🚀 Features
- Real-time sensor data collection using Arduino (Node 1 & Node 2)  
- Simulation and testing with **PICSim Lab**  
- Cloud dashboard integration with **ThingsBoard**  
- Monitoring factory parameters (temperature, vibration, etc.)  
- Visual representation of data for decision-making
